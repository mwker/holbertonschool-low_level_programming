# Holberton School - Programmation bas niveau

Ce dépôt contient mes projets de programmation en **C** réalisés dans le cadre du programme Holberton School.

Chaque projet se trouve dans son propre dossier, avec un `README.md` qui décrit ses objectifs et ses fichiers.

## Projets

| Dossier | Projet | Notions abordées |
|---|---|---|
| [`hello_world`](./hello_world) | C - Hello, World | Étapes de la compilation avec `gcc`, `puts`, `printf`, `sizeof` |
| [`variables_if_else_while`](./variables_if_else_while) | C - Variables, conditions (if, else) et boucles (while) | Variables, opérateurs, `if` / `else`, boucle `while`, `putchar` et table ASCII |
| [`functions_nested_loops`](./functions_nested_loops) | C - Fonctions et boucles imbriquées | Fonctions, prototypes, fichiers d'en-tête, portée des variables, boucles imbriquées |
| [`intro_debugging`](./intro_debugging) | C - Visualiser le débogage avec Python Tutor | Suivi pas à pas avec Python Tutor, correction d'erreurs de logique |
| [`more_functions_nested_loops`](./more_functions_nested_loops) | C - Plus de fonctions, plus de boucles imbriquées | Fonctions, boucles imbriquées, dessin de formes dans le terminal |

## Environnement

- Système : Ubuntu 20.04 LTS
- Compilateur : `gcc` avec les options `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Style de code : Betty
- Éditeurs : `vi`, `vim`, `emacs`
